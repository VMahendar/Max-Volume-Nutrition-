Pages

Add to page

Tap a photo, then Upload photo to replace it. Without selecting a photo, Upload adds a new photo to the page. Use Move / Resize on mobile; switch to Scroll Page when browsing.

Selected element

Click anything in the preview

Drag any selected element to move. Resize from four orange corners. Use Ctrl+C, Ctrl+X, Ctrl+V and Delete. No arbitrary size or movement limits.

Homepage canvas

Tap an element to select it. Drag directly to move or use any orange corner to resize. Save Draft keeps changes private.

Properties

Changes appear immediately in the preview.

Tap or click any photo, title, logo, banner, section or button. Drag the element itself to MOVE it. Pull any orange corner to RESIZE it.

Publish control

Save draft is private. Publish selected page updates only presentation overrides, never orders, product inventory, prices or checkout functions.
